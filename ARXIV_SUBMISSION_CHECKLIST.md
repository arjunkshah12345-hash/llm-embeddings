# arXiv submission checklist

This checklist describes the released final study and the checks required before uploading the source bundle. The paper reports a negative/mechanistic result for the tested regime; it does not claim that partial tying is a generally superior architecture.

## Submission metadata

- **Title:** Testing Role-Specific Corrections for Tied Input and Output Embeddings
- **Author:** Arjun Shah
- **Primary category:** `cs.LG`
- **Possible cross-list:** `cs.CL`
- **Peer-review status:** Open research preprint; no acceptance or peer review is implied.

## Completed evidence

- [x] Fresh 50k WikiText-2 primary comparison with tied, untied, rank-8 partial, and capacity control.
- [x] Three matched seeds: 1337, 2027, and 31415.
- [x] Three-seed 10k rank replication at ranks 1, 2, 4, 8, 16, and 32.
- [x] Three-seed smaller-scale WikiText-2 replication.
- [x] Three-seed Tiny Shakespeare replication.
- [x] Three-seed input-stop and output-stop path interventions.
- [x] Exact token-stream and final-step fairness validation for every collected study.
- [x] Paired seed comparisons, bootstrap intervals, parameter counts, FLOP estimates, throughput, and memory.
- [x] Effective matrix-space gradient/correction diagnostics and frozen representation probes.
- [x] Study 1 10k artifacts retained separately from final aggregates.

## Source bundle

- **Upload directory:** `arxiv/`

Before upload, inspect the compiled PDF pages for clipped tables, unreadable legends, missing references, and layout warnings. Confirm every headline number against `results/long_50k/primary_aggregate.json`, `results/rank_sweep/rank_aggregate.json`, `results/secondary/secondary_aggregate.json`, the mechanism aggregate, and the intervention aggregates.

## Claim gate

The final manuscript states that tied is strongest in the tested primary regime, untied is worse, and partial tying does not provide a stable quality advantage. It reports the uncertainty and limitations rather than converting the negative result into a broader architectural claim.
